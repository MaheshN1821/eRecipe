# eRecipe

## Overview
eRecipe is a frontend-only web application built using Bootstrap, designed to help users discover and explore a variety of recipes. The platform provides step-by-step cooking instructions, ingredient lists, and preparation methods for different cuisines.
Website - Link : https://maheshn1821.github.io/eRecipe/

## Features
- Extensive Recipe Collection: Provides a diverse collection of recipes, including detailed ingredients, preparation steps, and cooking time.
- User-Friendly & Responsive UI: Ensures a smooth experience across all devices, including mobile and desktop.

## Getting Started
To get started with eRecipe, clone the repository and open the `index.html` file in your web browser.

```bash
git clone https://github.com/MaheshN1821/eRecipe.git
cd eRecipe
open index.html
```
